# EmmyLua MCP Server 安装指南

## 1. 安装 / 更新插件

- 如果已安装旧版 EmmyLua，先在 VS Code 扩展面板中 **卸载**
- 点击扩展右上角 `…` → `Install from VSIX...`，选择提供的 `.vsix` 文件安装

## 2. 启动 MCP Server

- 按 `Ctrl+Shift+P` 打开命令面板
- 输入并选择 **EmmyLua: Start MCP Server**
- 打开 Output 面板（`Ctrl+Shift+U`），下拉选择 **EmmyLua MCP**，确认输出 `MCP server started at http://127.0.0.1:8827/mcp`

## 3. 在 MCP 客户端中配置

以 MyClicker（或任一 MCP 客户端）为例：

```json
{
  "mcpServers": {
    "emmylua-mcp": {
      "url": "http://127.0.0.1:8827/mcp",
      "type": "streamable-http"
    }
  }
}
- 不同客户端的配置入口不同，请参照其文档
- 如果端口被占用会 +1 重试，实际端口以 Output 面板为准
4. 使用工具
配置完成后，在支持 MCP 的 AI 对话界面中，AI 会自动识别并可使用 EmmyLua 工具：
- list_supported_languages — 查看支持的语言
- get_active_sessions — 查看调试会话
- launch — 启动新调试会话
- set_breakpoints / remove_breakpoints — 管理断点
- continue / pause / step_* — 控制执行
- evaluate — 求值表达式
- 更多工具见 mcp-config.json
